HTML Basics Tutorial

Welcome to my HTML tutorial page! HTML stands for HyperText Markup Language. It is used to create and structure content on web pages.

1. The Basic HTML Structure

Every HTML page normally has an <html>, <head>, and <body> section.

<HTML>

The <html> tag is the main container for the whole HTML document. Everything on the page is placed inside it.

<HEAD>

The <head> section contains information about the page, such as its title and character encoding. This information is not normally displayed as page content.

<BODY>

The <body> contains the content that visitors can see, such as headings, paragraphs, images, links and tables.

2. Headings

HTML has six heading levels, from <h1> to <h6>. The <h1> heading is the largest and most important heading.

3. Paragraphs

The <p> tag is used to create a paragraph. Paragraphs make text easier to read and organize.

This is another paragraph. HTML lets us separate different pieces of information into clear sections.

4. Line Breaks

The <br> tag creates a line break.
This text appears on a new line.
And this text appears on another new line.

5. Images

The <img> tag is used to display an image. The src attribute tells the browser where the image is. The alt attribute describes the image.

6. Links

The <a> tag creates a hyperlink. The href attribute specifies where the link goes.

<h1> - <h6> Creates different heading levels

Conclusion

HTML provides the basic structure of a web page. By combining headings, paragraphs, images, links, lists and tables, we can create an organized and useful web page.

Remember: HTML is about the structure and content of a webpage.
